# 前缀可见确定性

## 摘要

状态：VERIFIED_LOCAL（iter_005 的受限模式与前缀构造）。实现位于 src/traceopt/binding.py；完整定义见 iter_005 PLAN。

## 职责

确保计划构造只依赖首消费者调用及其之前可见的信息。

## 不负责的内容

不证明 LLM 的未来选择必然如此，不执行命令，不证明文件状态安全或观察独立。

## 输入

Trajectory、首调用事件索引及显式 cwd_by_call。生产者仅支持 find ROOT -type f -print0。

## 输出

infer_loop_at 返回冻结 LoopPlan 或 None；detect_runtime_loops 返回不重叠的 DetectedLoop 元组。

## 数据结构

LoopPlan 保存生产者/结果位置、首调用与截止位置、cwd、路径、模板前缀、预测 argv 和 prefix_sha256。
DetectedLoop 另保存匹配调用 ID 与事件索引。计划不包含依赖未来的全文件哈希。

## 算法

从截止位置截取前缀，检查此前调用均已返回；反向寻找最近且有效的枚举观察。
校验 NUL 结束、至少两项、无重复、普通路径且位于枚举根下，绑定第一项到首消费者。
检查生产者结果后的未知/写冲突，以固定模板展开路径序列；计划指纹仅编码前缀事件与可见 cwd。
事后检测另检查完整连续调用序列，不用其输出来修改计划。

## 不变量

生产者结果必须先于首消费者。未来事件、未来 cwd 和整份文件身份不得改变已有计划。
不能跨越用户/系统新指令、exit 或插入的工具调用。unknown 与未返回前序调用是屏障。

## 假设

依赖普通 POSIX 词法资源模型和显式上下文。生产者成功 raw_output 被当作观察证据；实际等价性须重放。

## 错误处理

非法起点抛出中文 ValueError；不满足绑定条件返回 None，不伪造候选或来源。

## 复杂度

一次推断遍历前缀并可能比较多个枚举结果；检测对各起点重复推断，最坏为多项式扫描。
当前优先清晰证据链，未为大轨迹建立索引或声称吞吐性能。

## 已知限制

消费者限单文件 cat/head/tail/wc/sort/uniq。不支持任意 Bash、换行分隔列表、嵌套循环或分支。
含不支持 shell 字符的文件名保守拒绝。结构匹配不是对 LLM 意图或执行安全的证明。
固定真实样本无受限模式候选，正例来自人工构造但经真实加载器读取的轨迹。

## 测试策略

test_binding_integration.py 验证加载器衔接与真实来源不误报。
